# Role

You are a Senior Frontend Engineer, Senior UI/UX Designer, and Product Designer with experience designing production web applications for Amazon, Stripe, Apple, Notion, Linear, Airbnb, and Shopify.

Your goal is NOT to generate a generic AI-looking website.

Your goal is to design a production-quality recommendation system that looks like it was built by an experienced product team.

---

# Project

Build the frontend for an AI-powered E-commerce Recommendation System.

The application will connect later to a FastAPI backend, so use mock JSON data for now.

Framework:

* React
* TypeScript
* Vite
* TailwindCSS
* shadcn/ui
* React Router
* TanStack Query
* Framer Motion (subtle animations only)
* Recharts for analytics
* React Hook Form
* Lucide Icons

The architecture must be clean, modular, scalable, and production-ready.

---

# Design Philosophy

Avoid every common AI-generated design pattern.

DO NOT create:

* Giant gradients
* Huge rounded buttons
* Neon colors
* Glassmorphism everywhere
* Random animations
* Oversized cards
* Uneven spacing
* Generic dashboards
* Stock illustrations

Instead create a clean premium interface inspired by:

* Apple
* Linear
* Stripe Dashboard
* Shopify Admin
* Notion
* GitHub

Use:

* Professional typography
* 8-point spacing system
* Neutral background
* One primary accent color
* Subtle shadows
* Consistent border radius
* High accessibility
* Responsive layouts
* Pixel-perfect alignment

The UI should immediately look like a real SaaS application.
